# AXIOMS.md — явный BIOS агента

Правило проекта: сырого опыта не существует; данность неустранима,
но обязана быть (1) объявленной, (2) короткой, (3) уменьшаемой.
Каждый эксперимент, сокращающий этот список, — результат.
Каждая необъявленная аксиома, найденная в коде, — баг.

## Аксиомы восприятия/действия (интерфейс)
- A1. Алфавит действий дан: read, write, delete, chmod, exec, create,
      kill, start + глаза-команды ls, ps. (exp0+)
- A2. Наблюдение — текст; токенизация по пробелам дана. (exp4)
      [до exp4 было сильнее: дана готовая разметка атрибутов — снято exp4]
- A3. Граница эпизода дана: (наблюдение, действие, результат) — один шаг.
- A4. Внимание дано: строка ls, относящаяся к цели действия, выбирается
      за агента. Сам он не решает binding problem "какая строка про что".
      [обнаружена задним числом в exp4 — кандидат на снятие]
- A5. Исход дан как атом: результат действия — стабильный, дискретный,
      взаимно-однозначный ярлык (RESULT_TEXT), а не текст для восприятия.
      Агент не токенизирует канал результатов и не может прочитать
      онтологию, протекающую в сообщениях об ошибках.
      [найдена спарринг-партнёром после exp4; путь снятия — растворение:
      токенизировать результат тем же A2, шум кластеризовать как в exp2]

## Аксиомы ядра (операторы)
- B1. MDL-пресс: знание = то, что сжимает опыт (правило принимается,
      если правило+исключения короче перечисления эпизодов).
- B2. Противоречия дороги: исключение стоит ~3x эпизода, иначе память
      становится самодовольной и понятия не рождаются (урок exp2).
- B3. Оператор латентных переменных: необъяснённый остаток -> постулируй
      скрытый предикат над k-кортежами объектов (k=1 класс, k=2 отношение),
      прими по B1. [с exp7 оба живут в петле сна под одним MDL-стражем;
      всё ещё два кода — сжатие в один оператор остаётся кандидатом]
- B5. Диагностика: правила читаются в обе стороны — из исхода зонда
      абдуцируется скрытый класс объекта ("yummy -> значит food").
      [добавлена в exp7: знание в памяти было, но без обратного чтения
      оставалось недоступным — знать и уметь достать не одно и то же]
      [exp9: + вывод методом исключения — если исход противоречит
      правилам всех значений переменной, кроме одного, ответ найден]
- B6. Смирение (долг раунда ores): точное воспоминание побеждает правило;
      правило отвечает только внутри области своих свидетелей (совместимых
      с запросом по значимым для теории атрибутам); вне — честное
      "не знаю" вместо уверенной экстраполяции. Отвечающий путь (answer)
      отделён от машинерии теории (predict): зубрёжка не должна убивать
      давление, из которого рождаются понятия.
- B4. Do-доступ: агент может вмешиваться, а не только наблюдать
      (без этого суеверия вечны — exp1).

## Аксиомы ставки
- C1. Драйв: эпистемический фронтир — действия, где нет правила ИЛИ
      правила ссылаются на неизмеренную переменную объекта. [реализован
      в exp5; уроки: (1) теория-всезнайка убивает любопытство — нужна
      неуверенность о неизмеренном, а не отсутствие ответа; (2) B1-страж
      обязателен и для B3 — изобретение без критика разрушает теорию;
      (3) новизна эпистемична: "пробовал контекст" != "пробовал объект".
      Полный learning progress (тренд ошибки) понадобится при шуме.]

## Снятые аксиомы (история сокращений)
- [exp2] "истинные переменные наблюдаемы" — снята: owner переизобретён
  из поведенческих сигнатур.
- [exp3] "структура мира унарна" — снята: отношение R(файл, процесс)
  абдуцировано из совпадений во времени.
- [exp4] "разметка наблюдения дана" — снимается: предикаты = позиции
  токенов в тексте, колонка owner должна быть открыта, а не дана.
- [exp6-7] "достаточно для одного мира" — снята: тот же BIOS (ядро +
  организм, менялся только перцептивный клей A) выучил второй мир
  (кухню): съедобность и связь "ключевой ингредиент -> блюдо"
  переизобретены, экзамены 8/8 в обоих мирах.
- [exp9] двухосевая ОС (owner + sealed) как проверка факторизации:
  выкурены амнезия групп (лечение — монотонное накопление симптомов),
  самоголодание любопытства (лечение — фронтир структуры: со-наблюдения
  для симптомов-сирот) и слепота вывода (лечение — метод исключения).
  Урок: любопытство — не ускоритель, а условие правильной структуры
  теории; случайный опыт даёт знание, не переносимое между симптомами.
- [exp8] "скрытая переменная одна" — необъявленная аксиома оператора B3,
  выкуренная третьим миром (математика: чётность И простота): общий
  симптом по одной оси склеивал объекты, различные по другой, — классы-
  химеры, костыльные правила, растущий остаток. Снята факторизацией:
  симптомы группируются по взаимной корреляции, одна латентная
  переменная на группу. Смесь по чужой оси внутри класса — признак
  правильно выделенной своей.

## Известное дно (не устраняется в принципе)
- Физика среды и смертность/цена ошибки. No free lunch: обучение без
  смещений невозможно; вопрос только в длине списка выше.
