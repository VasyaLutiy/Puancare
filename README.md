# Puancare / FormDevourer — Пожиратель Форм

**Слепой и немой организм, который ест миры, а хранит только форму:
спектр, темп, топологию.**

Организм живёт в мирах-загадках (yaml, слова непрозрачны), тычет в объекты,
из откликов и их динамики выучивает скрытую структуру (марковская ось +
правила под MDL-судьёй), выжимает из прожитого компактную карточку формы
и дальше узнаёт родню этой формы в любых словах — и переиспользует чужую
карту действий, сдавая экзамены на вопросы, которых сам никогда не пробовал.
Ни слов, ни обученных весов, ни констант в пути узнавания: пороги выводятся
из данных, поведение детерминировано, переименование всего мира не меняет
ни одного бита результата.

## Карта ветки

| слой | файлы | что делает |
|---|---|---|
| ядро (ЗАМОРОЖЕНО) | `organism2.py` | belief-фильтр, EM-оси, MDL-судья (групповой остаток) |
| полигон | `runworld.py`, `runworld2.py`, `worldkit.py`, `datalite.py`, `sig.py` | миры из анкет, прогоны, экзамены |
| линза | `koopman.py`, `fastpath.py` | спектральная подпись (мульти-k, шумовой пол), устойчивый выбор k без констант, быстрая дорога ~120мс |
| композиция | `compose.py` | ввоз чужой карты использования с выравниванием по роли |
| шкаф | `shelf.py`, `card.py`, `chest.py` | полка карточек форм (версия, ворота: парный тест + дрожь), сундук одной жизни |
| экзамены | `exam_shelf.py`, `exam_heldout3.py`, `EXAMS.md`, `exams_ledger.jsonl` | held-out протоколы, ведомость вердиктов |
| станок | `worldforge/` | слепой генератор миров-троек (внешняя LLM), гейт по заявленной структуре, партии |
| диагностика | `judge_probe.py`, `probe_k.py`, `compose_toggle.py` | вскрытие битов судьи, идентифицируемость k, развёртки |
| история | `attic/`, `MODEL.md`, `SPECTRA.md`, `AXIOMS.md` | замороженная модель, эссе арки Купмана, тупик переноса |

## Быстрая проверка, что всё живое

```
python3 test_shelf.py        # шкаф: 4/4 (персистентность, диета, версия, скорость)
python3 test_chest.py        # сундук держит
python3 repertoire.py        # узнавание форм: 4/4, порог новизны из библиотеки
python3 runworld2.py worlds/last/bact.yaml     # регрессия ядра на держи-ауте
```

Конвейер экзаменов (тройка донор/цель-зонд/цель):

```

```

## Что доказано (ведомость EXAMS.md; exams_ledger.jsonl — перепрогон
## 16.07 судьёй F3, exams_ledger.v3.jsonl — историческая; обе в репо)

- Немота: изоморфы с другими словами дают результаты бит-в-бит; 0 промахов
  на переименованиях за весь конвейер (5 слепых партий, 30 троек).
- Композиция: цель, жившая только зондом (0/8), сдаёт 8/8 чужой картой,
  выровненной по роли — включая миры, которых не видел ни один человек.
- Закон темпа: карта переносится при чужом темпе, если совпали топология
  и словарь исходов (3/3) — расстояние формы ≠ совместимость карты.
- Право отказа: чужие формы (глубже/иная топология) отвергаются порогом,
  выведенным из библиотеки.

## Протоколы (без них результаты не считаются)

1. Держи-ауты замораживаются коммитом (хэшами) ДО прогона; вскрытие —
   после вердикта. Ставки — до прогона, с проигрышными клетками.
2. Роли разделены: станок печатает вслепую, оператор кормит, арбитр
   судит по ведомости; автор гипотез не трогает прибор.
3. Насечка этапа: проверяется ТОЧНОСТЬ УПАКОВКИ форм. Извлечение смыслов
   и области применения — следующий этаж, вход закрыт.
