# Puancare / core

Ядро-костяк самообучающегося организма, конструирующего смыслы среды.
Ветка автономна: без общей истории с main и другими ветками.

## Состав

- `memory.py` — ядро: эпизодическая память + MDL-консолидация правил
  (знание = то, что сжимает опыт; противоречия дороги).
- `organism.py` — автономная петля: эпистемический фронтир (любопытство),
  сон, факторизованное изобретение скрытых переменных (k=1 классы,
  k=2 отношения) под MDL-стражем, диагностика по правилам + метод
  исключения.
- `AXIOMS.md` — явный BIOS: полный список врождённых смещений и журнал
  снятых аксиом по экспериментам.
- `WORLD_PROTOCOL.md` — контракт мира: что обязан предоставить любой мир
  (протокол, клей, требования R1-R8 к выучиваемой динамике).
- `conformance.py` — проверка соответствия мира протоколу + слепой
  прогон организма с экзаменами.
- `world.py` + `os2world.py` — эталонный мир (мини-ОС, две скрытые оси:
  владелец и печать), чтобы conformance был исполним из коробки.

## Конструктор миров (без единой строчки кода)

- `datalite.py` — крошечный Datalog: факты-кортежи, унификация,
  конъюнкции, негация, вывод до неподвижной точки.
- `worldkit.py` — анкета (YAML-подмножество, по-русски) -> клаузы ->
  GenericWorld + автоклей + `export_rules()` (замысел автора в формате
  памяти агента — для дифа "задумано против выученного").
- `runworld.py` — полигон автора: `--check` показывает мир глазами,
  без флага — полный прогон с организмом и экзаменами.
- `кухня.yaml` — регрессия конструктора (анкетная кухня == рукописная).
- `ШАБЛОН.yaml` — заготовка для нового мира с подсказками.

## Быстрая проверка, что всё живое

```
python3 conformance.py os2world      # эталонный мир-модуль
python3 conformance.py кухня.yaml    # мир из анкеты
python3 runworld.py ШАБЛОН.yaml --check
```

Ожидание: все проверки ok; экзамены 8/8 на бюджетах 300 и 2000.

## Результат, который несёт эта ветка

Формула, подтверждённая тремя мирами (ОС, кухня, математика-камешки)
при неизменном ядре: смысл строится под давлением — когда существо с
коротким явным списком врождённых операторов вынуждено дёшево
предсказывать последствия собственных действий, и ему дорого обходятся
противоречия. Подробности и границы применимости — в AXIOMS.md.
