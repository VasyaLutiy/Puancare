## 2. О чём спорили (зафиксированные решения, не мнения)

- **Не инженерная общность (плагины), а эпистемическая:** агент строит модель домена сам, а не человек кодирует каждый домен.
- **Предикат — не атом мира** (это ловушка Cyc / бесконечный регресс), а **тень пары (рычаг × сенсор) на цели**. Якорь = треугольник цель–рычаг–сенсор.
- **Знание = ГРАФ, не PDDL.** PDDL = машина добычи / ground-truth-валидатор. **6 мета-типов = ISA агента** (фиксированный контракт). NLU = компилятор человек→ISA. Неопределённый символ = триггер обучения.
- **Идентичность структурная, не смысловая:** вещь = (тип + рёбра + интервенции). Агент не знает человеческих понятий, только 6 типов. ⇒ индекс знания = структурная сигнатура.
- **Разделитель «не кэш ли это»:** песочница ОБЯЗАНА иногда переспорить LLM, иначе это LLM-фронтенд.
- **Одного docker-verify мало:** нужна богатая поверхность верификации (4 структурно разных измерения, включая межконтейнерную зависимость).

## 6. Перспективы (что это открывает)

- **Apply/retrieval (v5).** Идентичность = структурная сигнатура ⇒ выученную компетенцию можно ИЗВЛЕКАТЬ по структурному совпадению. Новая задача → матч сигнатуры с графом → переиспользование (0 LLM) или рост. Субстрат для этого готов (граф + кэш learned).
- **Кросс-доменный перенос.** Петля доменно-слепа, знание — типизированный граф ⇒ компетенция, выученная в одном домене («ordered_monotone → удвоение»), структурно переносится в ЛЮБОЙ домен с той же сигнатурой, не только devops.
- **Стратегии — ось обобщения.** Новый класс неизвестного = новая generic-стратегия по структуре (bounded уже добавлена за один заход). Расширяет агента на целый КЛАСС задач, не на один домен.
- **NLU как фронт-энд.** Back-end (петля) доказан; фрагмент = IR, packer = шлюз. NLU достраивается как компилятор NL→IR, неопределённый символ → та же петля.
- **Агент надёжнее своего LLM.** Рефьют (docker переспорил LLM) = механизм исправления неверных приоров LLM реальностью. Масштабируется на любой домен, где реальность может рассудить.
- **Аудируемое растущее знание** vs непрозрачный LLM: граф можно `cat`-нуть, он персистентен и заземлён в реальности. Это и есть отличие от LLM-фронтенда — теперь подтверждённое.
- **Следующий рубеж — недетерминизм.** Закон `unknown→verify→trust` обобщается на шумный мир: статистические стратегии, доверие с уверенностью p. Архитектура к этому готова.
